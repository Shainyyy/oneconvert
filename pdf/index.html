Which PDF Tool Do You Actually Need?

Most PDF problems fall into a handful of shapes, and picking the wrong tool wastes more time than the task itself. If you need part of a document, Split extracts a page range into a new file while leaving the original untouched, whereas Delete Pages keeps the document and removes pages from it. They are inverse operations: extracting pages 5–10 and deleting pages 1–4 and 11–end produce the same result, but the first is quicker when you want a small slice and the second when you want to drop a few pages from a long file.

If a file is too large to email, start by identifying why. Compress strips metadata and repacks the internal object structure — effective on text-heavy documents, close to useless on scans, where nearly all the weight is image data. A scanned file that will not shrink is usually better handled by removing pages you do not need to send.

For assembly and presentation, Merge combines files in the order you arrange them, Reorder rearranges pages within one document, and Rotate fixes pages scanned sideways. Apply Page Numbers last — numbers are drawn onto the page, so any later split, merge or reorder puts them out of sequence.

Conversions are the operations with real trade-offs. PDF to Word reads the text layer and rebuilds paragraphs, so it works on documents whose text you can select and returns nothing from a scan. PDF to Images and Grayscale both rasterise the page, which means the output is pictures: no selectable text, no working links, and often a larger file. Each tool's page explains its specific limits — worth two minutes before processing something important.
